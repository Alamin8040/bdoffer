# BD Offer Landing Page

## ব্যবহার
1. ZIP extract করুন।
2. `index.html` ব্রাউজারে খুললে website দেখা যাবে।
3. `script.js`-এ নিজের WhatsApp নম্বর বসান।
4. `index.html`-এ demo offer-এর নাম ও দাম পরিবর্তন করুন।

## GitHub Pages
- GitHub-এ নতুন repository তৈরি করুন।
- সব ফাইল upload করুন।
- Settings > Pages > Deploy from a branch > main > root নির্বাচন করুন।
